# Capstone-2025

## Comandos para iniciar el proyecto:
1. bash```python manage.py makemigrations``` (Iniciar migraciones generales)
2. `python manage.py makemigrations` home (Iniciar migraciones desde la app home)
3. `python manage.py migrate` (Confirmar y aplicar migraciones)
4. `python manage.py createsuperuser` (Crear cuenta administrador dentro del sistema)
5. `python manage.py runserver` (Correr el servidor de desarollo)
