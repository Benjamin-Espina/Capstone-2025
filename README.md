## Comandos para iniciar el proyecto:
1. Iniciar migraciones generales
bash
```
python manage.py makemigrations
```
2. Iniciar migraciones desde la app home
bash
```
python manage.py makemigrations home
```
3. Confirmar y aplicar migraciones
bash
```
python manage.py migrate
```
4. Crear cuenta administrador dentro del sistema
bash
```
python manage.py createsuperuser
```
5. Correr el servidor de desarollo
bash
```
python manage.py runserver
```
